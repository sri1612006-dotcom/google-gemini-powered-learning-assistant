# 15. Security and Responsible AI

## Security
- Keep Gemini API keys in environment variables.
- Never commit `.env` files.
- Validate and sanitize user input.
- Use HTTPS in production.
- Apply rate limiting where appropriate.
- Do not expose private server credentials in frontend JavaScript.

## Responsible AI
- Inform users that AI responses may contain mistakes.
- Encourage verification for important academic facts.
- Avoid generating harmful or inappropriate content.
- Minimize collection of personal data.
- Provide clear error messages rather than hiding failures.

## GitHub Security
The repository should contain `.env.example`, not the real `.env` file.
