# 18. Advantages and Limitations

## Advantages
- Fast access to learning assistance.
- Interactive question answering.
- Flexible educational prompts.
- Can support multiple subjects.
- Easy to extend with additional modules.
- Web-based and accessible across devices.

## Limitations
- AI responses can contain factual errors.
- Requires internet connectivity.
- API usage may have quotas or costs.
- Response quality depends on prompt quality.
- Basic versions may not retain learning history.
- Generated content should be reviewed before academic submission.
