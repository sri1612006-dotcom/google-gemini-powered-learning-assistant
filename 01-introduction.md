# 1. Introduction

EduGenie – Google Gemini Powered Learning Assistant is a web-based educational application that uses generative AI to support students during learning. The system provides quick explanations, question answering, summaries, quizzes, revision support and learning recommendations through a simple interface.

The project is designed to demonstrate how a modern web application can integrate an AI/LLM service into an educational workflow. Users enter a learning request, the application validates the input, sends an appropriate prompt to the AI service and displays the generated response in an understandable format.

## Key Features
- AI-powered question answering
- Topic explanations in simple language
- Text summarization
- Quiz generation
- Revision assistance
- Learning recommendations
- Responsive web interface
- API-based Gemini integration

## Project Goal
The main goal is to make learning support faster, interactive and accessible while keeping the student in control of what they study.
