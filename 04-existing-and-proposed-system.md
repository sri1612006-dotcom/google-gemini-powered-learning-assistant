# 4. Existing and Proposed System

## Existing System
Conventional learning systems generally depend on static notes, predefined question banks and search engines. They are useful for reference but may require users to combine information from several sources.

## Proposed System
EduGenie provides a conversational AI-assisted learning experience. A student can submit a topic or question and receive a generated response.

| Existing Approach | EduGenie |
|---|---|
| Mostly static content | Dynamic AI-generated content |
| Manual searching | Direct question interface |
| Fixed quizzes | Generated practice questions |
| Limited personalization | Prompt-based customization |
| Multiple resources | Central learning assistant |

The AI output should be treated as learning assistance and verified against trusted academic sources when accuracy is important.
