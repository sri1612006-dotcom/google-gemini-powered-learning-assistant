# 14. Testing and Validation

Testing ensures that the application behaves correctly.

## Functional Tests

| Test | Expected Result |
|---|---|
| Empty prompt | Validation message |
| Valid question | AI response displayed |
| Long invalid input | Input rejected or limited |
| API failure | User-friendly error |
| Server unavailable | Connection error shown |
| Mobile screen | Responsive interface |

## API Testing
Use browser tools, Postman or similar tools to test API endpoints.

## User Validation
A small set of sample educational questions can be used to check clarity, relevance and response formatting. AI-generated answers should be reviewed for factual accuracy.
