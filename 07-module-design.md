# 7. Module Design

## 7.1 User Interface Module
Provides topic input, question input, buttons and response display.

## 7.2 Learning Assistant Module
Accepts user requests and sends them to the backend.

## 7.3 Prompt Management Module
Creates task-specific prompts for explanation, summarization and quiz generation.

## 7.4 Gemini Integration Module
Connects the backend to Google's Gemini API and receives model responses.

## 7.5 Validation Module
Checks input length, required fields and acceptable request types.

## 7.6 Error Handling Module
Displays useful messages when the network, API or server fails.
