# 12. Prompt Engineering

Prompt engineering is used to guide the model toward useful educational responses.

## Example Prompt
```text
You are an educational assistant.
Explain the following topic for a college student.
Use simple language, headings and examples.
Do not invent sources or facts.
Topic: {topic}
```

## Prompt Guidelines
- State the assistant's role.
- Specify the learner level.
- Define the required output format.
- Give the exact task.
- Ask for concise and understandable language.
- Avoid requesting unsupported facts.
- Treat generated information as assistance that may require verification.
