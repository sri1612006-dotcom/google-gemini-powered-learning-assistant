# 5. System Requirements

## Hardware
- Dual-core processor or better
- 4 GB RAM minimum
- 1 GB available storage for project dependencies
- Internet connection

## Software
- Windows, Linux or macOS
- Visual Studio Code
- Node.js and npm
- Modern web browser
- Git and GitHub account
- Google Gemini API access

## Development Requirements
- Frontend framework: React or equivalent
- Backend: Node.js/Express or equivalent
- Environment variables for API credentials
- Git for version control

## Recommended
- 8 GB RAM or higher
- Node.js LTS
- Chrome/Edge/Firefox latest stable version
