# 11. Frontend Design

The interface should be simple enough for students to use without technical knowledge.

## Main UI Sections
1. Application header
2. Topic/question input
3. Learning mode selector
4. Generate button
5. AI response card
6. Error/status message
7. Optional history section

## Design Principles
- Responsive layout
- Clear typography
- Accessible buttons and forms
- Loading indicator during AI generation
- Mobile-friendly design
- Clear separation between input and generated answer
